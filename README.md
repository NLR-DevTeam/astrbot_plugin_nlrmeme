# Astrbot NLR MEME
适用于 Astrbot 的 NLR MEME 插件  
能调用 [NLR MEME](meme.nlrdev.top) 的 MEME/梗图  

### 指令
| 指令名称 | 介绍           |
|:---------|:---------------|
| meme     | 获取一张meme图 |

### 配置项

| 名称                   | 介绍                         | 默认值 | 单位   |
|:-----------------------|:-----------------------------|--------|--------|
| 指令冷却时间           | 使用指令后再次使用的冷却时间 | 30     | 秒     |
| 超时时长               | 调用meme图的时限，超时则报错 | 15     | 秒     |
| 管理员是否不受冷却影响 | 管理员是否不受冷却的影响     | true   | 布尔值 |


API来源：[YanJi](https://github.com/YanJi314)
